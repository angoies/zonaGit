    Markdown¶

    1. Introducción¶

    Markdown[9] is a lightweight markup language for creating formatted text using a plain-text editor. John Gruber and Aaron Swartz created Markdown in 2004 as a markup language that is appealing to human readers in its source code form.

    Its key design goal was readability, that the language be readable as-is,

    Tenga en cuenta que hay versiones. Por ejemplo GitHub nos dice:

    1.1What is GitHub Flavored Markdown?

    GitHub Flavored Markdown, often shortened as GFM, is the dialect of Markdown that is currently supported for user content on GitHub.com and GitHub Enterprise.

    This formal specification, based on the CommonMark Spec, defines the syntax and semantics of this dialect.

    GFM is a strict superset of CommonMark. All the features which are supported in GitHub user content and that are not specified on the original CommonMark Spec are hence known as extensions, and highlighted as such.

    2. Utilización¶

    Posibles usos de Markdown

    • Documentación técnica (permite control de versiones).
    • Uso en los repositorios de GitHub (preprocesa el formato Markdown para previsualizarlo).
    • Uso conjunto con la herramienta mkdocs y GitHub Pages.
    • Otros posibles usos:
    • Esquemas con la herramienta markmap.
    • Presentaciones tipo slides con la herramienta marp.

    3. sintaxis básico¶

    En general debe ser suficiente conocer este conjunto de marcas:

    • Cabeceras de nivel
    • Párrafos
    • Citas
    • strong / em
    • Listas
    • Enlaces
    • Imágenes
    • Código en línea
    • Bloques de código (con especificación del lenguaje)

    Puede ampliar con otras marcas como:

    • Tablas
    • Listas de tareas
    • emoticonos
    • separadores

    En este enlace encontrará ejemplos sencillos del uso de todas estas marcas: Sintaxis básica de Markdown. Se muestra a continuación un resumen abreviado de las mismas.

    Primer ejemplo: cabeceras, párrafos, cita, negrita y cursiva

    # Título: Cabecera nivel 1

Esto es un párrafo, no lleva marcas. 

El texto en negita o cursiva se marca con `*`. Por ejemplo **destacamos esta parte del párrafo en negrita** y *esta otra en cursiva*.

    4. Tareas propuestas¶

    • Crear documento Markdown. Incluir distintos tipos de marcas.
